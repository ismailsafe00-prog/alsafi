# نظام الصافي للمفروشات 🏠
## AlSafi Accounting System

نظام محاسبة احترافي كامل مخصص لمحلات بيع المفروشات والسجاد

---

## ✨ الميزات الرئيسية

### 1. شاشة تسجيل الدخول
- واجهة احترافية وجذابة
- بيانات تسجيل اختبار مدمجة
- إنشاء مستخدمين جدد (بائع/مدير نظام)

**بيانات الاختبار:**
- اسم المستخدم: `ismail`
- كلمة المرور: `ismail1234`

### 2. لوحة التحكم
- ترحيب شخصي باسم المستخدم
- 6 بطاقات إحصائية ملونة
- رسم بياني لحركة المبيعات (آخر 7 أيام)
- آخر 5 معاملات فعلية

### 3. نقطة البيع (POS)
- واجهة سهلة لإضافة المنتجات
- إدخال بيانات العميل
- حساب الخصم والضريبة تلقائياً
- طباعة الفواتير

### 4. إدارة الفواتير
- عرض جميع الفواتير السابقة
- البحث والفلترة
- معاينة وطباعة

### 5. العروض والخصومات
- إضافة عروض مع صور
- تحديد فترات زمنية
- إدارة الخصومات

### 6. إدارة المستودع
- إضافة/تعديل/حذف المنتجات
- اختيار الوحدة (قطعة / متر / متر مربع)
- تتبع الأسعار

### 7. التقارير
- تقارير مبيعات يومية/شهرية
- تقارير أرباح المنتجات
- تقارير المخزون

### 8. إدارة المستخدمين
- إضافة مستخدمين جدد
- تحديد الأدوار (بائع/مدير)
- حذف المستخدمين

### 9. رابط العروض العام
- رابط خاص للزبائن
- واجهة عامة احترافية
